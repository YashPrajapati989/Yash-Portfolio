# 🌌 Project Context

**Project Name:** Yash Portfolio

**Version:** 1.0

---

# Overview

Yash Portfolio is not a traditional developer portfolio.

It is a premium, cinematic, storytelling-driven web experience designed to showcase not only projects, but also the mindset, process, and engineering philosophy behind them.

The goal is to make visitors remember **how the creator thinks**, not simply what technologies they know.

---

# Mission

Design and develop a portfolio that demonstrates world-class frontend engineering, storytelling, UI craftsmanship, accessibility, performance, and software architecture.

The portfolio itself should be treated as the flagship project.

---

# Vision

To create a portfolio that feels like exploring a modern digital product rather than scrolling through a résumé.

Every interaction should communicate professionalism, curiosity, and attention to detail.

Primary Background

Midnight Black

Secondary Surface

Dark Slate

Accent Colors

- Electric Blue
- Soft Cyan
- Subtle Violet

Text

- White
- Light Gray
- Muted Gray

---

# Typography Philosophy

Typography should create hierarchy.

Large headings.

Comfortable reading width.

Generous spacing.

Minimal paragraph length.

Readable at every screen size.

---

# Motion Philosophy

Animation exists to support storytelling.

Every animation must communicate something.

Motion should:

Guide attention

Explain transitions

Improve orientation

Create continuity

Never animate purely for decoration.

---

# 3D Philosophy

Three.js should be used sparingly.

The Intelligence Core acts as the central visual identity.

3D should enhance immersion without affecting performance.

No unnecessary complexity.

---

Remember at least one project.
